# xhs-frontend 项目说明文档

> 仿小红书高并发内容社区系统 —— 前端基线版（Day0）

---

## 1. 项目简介

本项目是一个**仿小红书的内容社区系统前端**，采用前后端分离架构，以单页应用（SPA）形式提供：

- 笔记瀑布流浏览（推荐 / 关注 / 热门三种频道）
- 笔记详情查看与互动（点赞、收藏、关注作者、评论）
- 笔记发布
- 关键词搜索
- 用户登录、个人主页（笔记 / 关注 / 粉丝）

前端通过 axios 调用后端 REST API（所有请求以 `/api` 为前缀），由 Vite 开发服务器代理转发至后端（`http://localhost:8080`）。

## 2. 主要框架与技术栈

| 类别 | 技术 | 版本 | 主要作用 |
| --- | --- | --- | --- |
| 核心框架 | **Vue 3** | ^3.4.21 | 组件化开发、响应式数据绑定，全部使用 `<script setup>` 组合式 API |
| 路由 | **vue-router 4** | ^4.3.0 | SPA 路由管理，路由懒加载 + HTML5 History 模式 |
| UI 组件库 | **Element Plus** | ^2.6.3 | 表单、弹窗、标签页、消息提示等 UI 组件（含中文语言包与图标库） |
| HTTP 客户端 | **axios** | ^1.6.8 | 与后端通信，配合拦截器统一处理身份与错误 |
| 构建工具 | **Vite** | ^5.2.8 | 本地开发服务器（5173 端口）+ API 代理 + 生产构建 |

**登录态方案**：登录成功后将用户信息存入 `localStorage`，之后所有请求由 axios 请求拦截器自动附加 `X-User-Id` 请求头（基线方案，简化版身份识别）。

## 5. 模块详解与关键代码

### 5.1 应用入口与根组件（main.js / App.vue）

**作用**：创建 Vue 应用实例，注册 Element Plus（中文语言包）与路由，挂载到 `#app`；`App.vue` 提供全站共享的顶部导航栏（搜索框、登录状态、退出）和路由出口。

```js
// main.js
const app = createApp(App)
app.use(ElementPlus, { locale: zhCn })
app.use(router)
app.mount('#app')
```

**关键设计**：登录成功后 `Login.vue` 派发 `xhs-user-changed` 自定义事件，`App.vue` 监听该事件刷新导航栏的用户昵称，实现跨组件登录态同步：

```js
// App.vue
window.addEventListener('xhs-user-changed', refreshUser)

function doSearch() {
  if (!keyword.value.trim()) return
  router.push({ path: '/search', query: { kw: keyword.value.trim() } })
}
```

### 5.2 路由模块（router/index.js）

**作用**：定义 6 条路由，全部使用**动态 import 懒加载**（按路由分包，首屏只加载当前页代码），采用 HTML5 History 模式。

| 路径 | 组件 | 说明 |
| --- | --- | --- |
| `/` | Home | 首页笔记流 |
| `/note/:id` | NoteDetail | 笔记详情（动态路由参数） |
| `/publish` | Publish | 发布笔记 |
| `/user/:id` | UserHome | 用户主页 |
| `/search` | Search | 搜索结果（关键词走 query 参数 `?kw=`） |
| `/login` | Login | 登录 |

```js
const routes = [
  { path: '/', name: 'Home', component: () => import('../views/Home.vue') },
  { path: '/note/:id', name: 'NoteDetail', component: () => import('../views/NoteDetail.vue') },
  // ... 其余路由同样懒加载
]
const router = createRouter({ history: createWebHistory(), routes })
```

### 5.3 API 通信层（api/index.js）—— 项目核心

**作用**：统一封装与后端的所有交互。一个 axios 实例 + 两个拦截器，导出按业务分组的 API 函数（笔记 / 互动 / 评论 / 用户）。

**① 请求拦截器：自动携带身份**

```js
const request = axios.create({ baseURL: '/api', timeout: 10000 })

request.interceptors.request.use(config => {
  const user = currentUser()
  if (user) {
    config.headers['X-User-Id'] = user.id   // 后端据此识别当前用户
  }
  return config
})
```

**② 响应拦截器：统一解包与错误处理**

后端返回格式为 `{ code, msg, data }`。拦截器将业务数据直接解包返回，业务失败或网络异常统一弹 `ElMessage` 提示，页面代码因此**无需重复写 try/catch 错误提示**：

```js
request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.msg || '请求失败')
      return Promise.reject(res)
    }
    return res.data          // 页面拿到的直接是业务数据
  },
  error => {
    ElMessage.error('网络异常，请稍后重试')
    return Promise.reject(error)
  }
)
```

**③ API 函数分组（节选）**

```js
// 笔记
export const getLatestNotes = (page = 1, size = 10) =>
  request.get('/notes/list', { params: { page, size } })
export const getNoteDetail = id => request.get(`/notes/${id}`)
export const publishNote = data => request.post('/notes', data)

// 互动（点赞/收藏：POST 添加、DELETE 取消）
export const likeNote = id => request.post(`/notes/${id}/like`)
export const unlikeNote = id => request.delete(`/notes/${id}/like`)

// 用户
export const login = (username, password) =>
  request.post('/users/login', { username, password })
export const followUser = id => request.post(`/users/${id}/follow`)
```

### 5.4 登录态管理（utils/user.js）

**作用**：基线版登录态方案 —— 用户信息（id、nickname 等）序列化为 JSON 存入 `localStorage`，提供读、存、清、判断登录 4 个工具函数：

```js
const KEY = 'xhs-user'

export function currentUser() {
  const raw = localStorage.getItem(KEY)
  return raw ? JSON.parse(raw) : null
}
export function saveUser(user) { localStorage.setItem(KEY, JSON.stringify(user)) }
export function clearUser() { localStorage.removeItem(KEY) }
export function isLoggedIn() { return !!currentUser() }
```

### 5.5 首页模块（views/Home.vue）

**作用**：通过 `el-tabs` 切换 **推荐（最新）/ 关注 / 热门** 三个频道，加载对应笔记列表并以 `NoteCard` 网格渲染；"关注"频道未登录时给出引导提示而非发请求。

```js
async function load() {
  loading.value = true
  try {
    if (activeTab.value === 'latest') {
      notes.value = await getLatestNotes(1, 20)
    } else if (activeTab.value === 'hot') {
      notes.value = await getHotNotes()
    } else {
      // 未登录不请求关注流，直接展示空态引导
      notes.value = isLoggedIn() ? await getFollowNotes(1, 20) : []
    }
  } catch (e) {
    notes.value = []
  } finally {
    loading.value = false
  }
}
```

### 5.6 笔记详情与互动模块（views/NoteDetail.vue）—— 功能最复杂的页面

**作用**：展示笔记正文、标签、作者卡片；提供点赞、收藏、关注作者的**状态切换**，以及评论的发布与列表刷新。

**① 乐观式交互（以点赞为例）**：请求成功后立即本地更新状态与计数，不重新拉取整个详情，交互即时响应：

```js
async function toggleLike() {
  if (!requireLogin()) return
  try {
    if (note.value.liked) {
      await unlikeNote(noteId)
      note.value.liked = false
      note.value.likeCount--
    } else {
      await likeNote(noteId)
      note.value.liked = true
      note.value.likeCount++
    }
  } catch (e) { /* 拦截器已提示 */ }
}
```

**② 统一的登录守卫**：所有写操作前先检查登录态，未登录则提示并跳转登录页：

```js
function requireLogin() {
  if (!isLoggedIn()) {
    ElMessage.warning('请先登录')
    router.push('/login')
    return false
  }
  return true
}
```

**③ 评论提交后刷新列表**：

```js
async function submitComment() {
  if (!requireLogin() || !commentText.value.trim()) return
  await addComment(noteId, commentText.value)
  commentText.value = ''
  comments.value = await getComments(noteId)   // 重新拉取保证顺序/数据一致
  note.value.commentCount++
}
```

### 5.7 发布笔记模块（views/Publish.vue）

**作用**：`el-form` 表单收集标题（限 100 字）、正文（限 2000 字）、标签（逗号分隔），校验非空后提交，成功后携带后端返回的新笔记 id 直接跳转到详情页：

```js
async function submit() {
  if (!form.title.trim() || !form.content.trim()) {
    ElMessage.warning('标题和正文不能为空')
    return
  }
  loading.value = true
  try {
    const id = await publishNote(form)
    ElMessage.success('发布成功')
    router.push(`/note/${id}`)   // 发布成功直达详情页
  } catch (e) { /* 拦截器已提示 */ } finally {
    loading.value = false
  }
}
```

### 5.8 搜索模块（views/Search.vue）

**作用**：关键词通过 URL query（`?kw=xxx`）传递，页面加载时执行搜索；并用 `watch` 监听关键词变化，实现**同一路由下连续搜索不刷新页面**：

```js
const kw = computed(() => route.query.kw || '')

async function load() {
  if (!kw.value) { notes.value = []; return }
  loading.value = true
  try {
    notes.value = await searchNotes(kw.value, 1, 20)
  } catch (e) { notes.value = [] } finally { loading.value = false }
}

watch(kw, load)      // 在 /search 页再次搜索时自动重新加载
onMounted(load)
```

### 5.9 用户主页模块（views/UserHome.vue）

**作用**：展示任意用户的资料（昵称、签名、笔记/关注/粉丝数）与其笔记网格；点击"关注/粉丝"数字弹出 `el-dialog` 列表；访问他人主页显示关注按钮。

**关键点①：`watch(userId, load)`** —— 从关注/粉丝列表点进另一个用户时，同一组件复用但参数变化，靠 watch 重新加载：

```js
const userId = computed(() => route.params.id)
watch(userId, load)
onMounted(load)
```

**关键点②：判断是否访问自己**，自己访问自己时隐藏关注按钮：

```js
const isSelf = computed(() => {
  const me = currentUser()
  return me && String(me.id) === String(userId.value)
})
```

**关键点③：关注后本地同步粉丝数**（`fansCount++/--`），与 NoteDetail 的点赞计数同理。

### 5.10 笔记卡片组件（components/NoteCard.vue）

**作用**：首页、搜索页、用户主页复用的展示单元。点击整卡跳转详情；**无图片环境下根据笔记 ID 取模生成固定渐变封面**，保证离线也有视觉效果：

```js
const gradients = [
  'linear-gradient(135deg, #ff9a9e, #fad0c4)',
  'linear-gradient(135deg, #a18cd1, #fbc2eb)',
  // ... 共 6 组渐变
]
const coverGradient = computed(() => gradients[(props.note.id || 0) % gradients.length])
```

## 7. 运行与构建

| 命令 | 说明 |

## 8. 小结

| 设计要点 | 体现位置 | 收益 |
| --- | --- | --- |
| 路由懒加载 | `router/index.js` | 首屏只加载当前页代码，减小初始包体 |
| 拦截器统一处理 | `api/index.js` | 身份注入与错误提示集中管理，页面代码极简 |
| 响应数据解包 | 响应拦截器 | 页面直接使用业务数据，无需关心 `{code, msg, data}` 外壳 |
| 乐观式本地更新 | NoteDetail / UserHome | 点赞、收藏、关注即时反馈，减少整页刷新 |
| 组件复用 | NoteCard | 首页/搜索/用户主页共用同一卡片 |
| watch 参数复用 | Search / UserHome | 同路由下参数变化自动重载，无需刷新页面 |
